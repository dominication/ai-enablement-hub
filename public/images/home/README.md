# Homepage visuals

The hero is an AI-generated image of fictional colleagues, created for this prototype using the approved homepage mockup as a composition reference. It is stored locally as a compressed WebP; there are no external image requests.

The recruiting, project, team and notes SVGs are original static illustrations following the motifs in the approved reference. All visuals are decorative; content and destinations remain accessible as text.

The three `learning-*.svg` thumbnails are separate editorial scenes for meeting notes, contextual project information and team reflection. They are not reused journey illustrations and contain no measured progress or data.
